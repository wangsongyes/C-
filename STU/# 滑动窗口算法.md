# 滑动窗口算法

@FCPS 用C语言：Hitori
 一共交到了 m
 个朋友，每个朋友都有一种独一无二的颜色。为了方便，我们用数字来表示每位朋友的颜色，即：第 i
 位朋友的颜色为 i
 。

这一天，Hitori
 又在坐地铁。她发现线路图上从左到右一共有 n
 个换乘站，第 i
 个换乘站对应的线路颜色为 ai
 ，并且 1≤ai≤m
 。对于这样一个由颜色构成的序列， Hitori
 将其称为整数序列 a
 。

Hitori
 想起了她的 m
 个朋友，她想知道，在序列 a
 中，有多少个长度为 m
 的子段，满足在子段中，每位朋友的颜色都恰好只出现了一次。

说明： 一个序列是 a
 的子段，当且仅当该序列由若干个 a
 中连续的元素按顺序组成。如，[1,2,3]
 和 [3,3,5]
 是 [1,2,3,3,5]
 的子段，但 [1,3,5]
 和 [1,3,2]
 不是。

输入
输入包含两行。

第一行包含两个整数 n,m
 ，分别表示序列 a
 的长度和 Hitori
 朋友的数量。

第二行包含 n
 个整数 a1,a2,a3,⋯,an  (1≤ai≤m)
，表示颜色序列 a
 。

输出
输出一行，包括一个整数，表示满足要求的子段数量。

# Answer

要解决这个问题，可以使用滑动窗口的算法。目标是找到所有长度为 m 的子段，并确保在这个子段中每种颜色都恰好出现一次。

下面是使用 C语言实现该问题的代码：

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    
    int *a = (int *)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }
    
    int count = 0;
    
    // 用于记录当前窗口中每个颜色的计数
    int *color_count = (int *)calloc(m + 1, sizeof(int));
    int unique_colors = 0; // 记录当前窗口中唯一颜色的数量

    for (int i = 0; i < n; i++) {
        // 将当前颜色加入窗口
        if (a[i] >= 1 && a[i] <= m) {
            if (color_count[a[i]] == 0) {
                unique_colors++;
            }
            color_count[a[i]]++;
        }
        
        // 当窗口大小超过 m 时，移除最左边的元素
        if (i >= m) {
            if (a[i - m] >= 1 && a[i - m] <= m) {
                color_count[a[i - m]]--;
                if (color_count[a[i - m]] == 0) {
                    unique_colors--;
                }
            }
        }
        
        // 如果窗口的大小为 m，并且所有颜色都出现一次
        if (i >= m - 1 && unique_colors == m) {
            count++;
        }
    }

    printf("%d\n", count);

    free(a);
    free(color_count);
    
    return 0;
}
```

### 代码解析：
1. **输入部分**：读取序列的长度 `n` 和朋友数量 `m`，然后读取颜色序列 `a`。
2. **滑动窗口**：使用一个大小为 `m` 的窗口，记录当前窗口内每种颜色的出现次数。
3. **更新窗口**：每次添加新的颜色时，检查是否为新的颜色（即计数从0变为1），并更新当前唯一颜色数量。当窗口大小超过 `m` 时，移除最左边的颜色并更新计数。
4. **满足条件的计数**：每当窗口大小达到 `m` 并且唯一颜色数量等于 `m` 时，增加计数。
5. **输出结果**：最后输出满足条件的子段数量。

整体时间复杂度为 O(n)，因为每个元素最多只被访问两次。希望这个解法能够满足你的需求！
