# Question

C语言差分数组

# Answer

差分数组是一种高效处理区间更新的问题的数据结构。我们通过维护一个差分数组来实现对原数组的快速修改。差分数组的核心思想是，利用局部变化来推导出整体的变化。

### 差分数组的基本原理

给定一个数组 `arr`，其差分数组 `diff` 满足：
- `diff[i] = arr[i] - arr[i-1]` （对于 `i > 0`）
- `diff[0] = arr[0]`

通过操作差分数组，可以在 `arr` 上实现区间更新，比如对 `arr[l]` 到 `arr[r]` 的所有元素加上一个值 `x`，可以通过更新 `diff` 数组来实现：
- `diff[l] += x` （从 `l` 开始加 `x`）
- `diff[r+1] -= x` （从 `r+1` 开始减 `x`）

### 示例代码

以下是一个使用差分数组进行区间更新的 C 语言示例代码：

```c
#include <stdio.h>

#define MAX_SIZE 100 // 宏定义数组最大长度

void printArray(int arr[], int size) { // 打印数组
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

void updateRange(int diff[], int n, int l, int r, int x) { // 区间更新，n表示数组大小，l表示左端点，r表示右端点，x表示增量
    diff[l] += x;
    if (r + 1 < n) {
        diff[r + 1] -= x; // 注意：r+1表示右端点的下一个位置
    }
}

void applyDiff(int arr[], int diff[], int n) { // 应用差分数组
    arr[0] = diff[0]; // 第一个元素不用更新
    for (int i = 1; i < n; i++) {
        arr[i] = arr[i - 1] + diff[i];
    }
}

int main() {
    int arr[MAX_SIZE] = {1, 2, 3, 4, 5}; // 原数组
    int n = 5; // 数组大小
    int diff[MAX_SIZE] = {0}; // 差分数组

    for (int i = 0; i < n; i++) {
        updateRange(diff, n, i, i, arr[i]); // 初始化差分数组
    }

    printf("原数组: ");
    printArray(arr, n);

    // 对区间 [1, 3] 加 10
    int l = 1, r = 3, x = 10;
    updateRange(diff, n, l, r, x);

    // 应用差分数组到原数组
    applyDiff(arr, diff, n);

    // 打印更新后的数组
    printf("更新后的数组: ");
    printArray(arr, n);

    return 0;
}
```
